<<「無法確認發行者，您確定要執行這個軟體？」警告解決>>

說明：

解決使用<網路芳齡(網路磁碟機)> 啟動<遠端電腦>中的<執行檔(EXE)>

會跳出「無法確認發行者，您確定要執行這個軟體？」告警問題之解決方案。

 

適用：

Windows Vista / Server 2008

Windows 7 / Server 2008 R2

Windows 8 / Server 2012

Windows 8.1 / Server 2012 R2

Windows 10 / Server 2016 / Server 2019 / Server 2022

Windows 11

 

方法：

1. 至 <控制台> \ 網際網路選項 \ 安全性 \ <近端內部網路> \ 網站 \ 進階

2. 在最上面「網址輸入框」輸入要加入<白名單>的路徑。

網址輸入範例：

\\192.168.2.5\

Z:\

3. 按下「關閉」按鈕
