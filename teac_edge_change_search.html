<<Microsoft EDGE 更改預設搜尋引擎>>

簡述：

<EDGE瀏覽器>預設在<網址列>輸入關鍵字進行搜尋，預設是使用<微軟BING搜尋引擎>，如果要改為其他第三方搜尋引擎(例如Google搜尋引擎>，可以使用以下方式修改。

支援：

Microsoft Windows 7 Edge 瀏覽器

Microsoft Windows 8 Edge 瀏覽器

Microsoft Windows 8.1 Edge 瀏覽器

Microsoft Windows 10 Edge 瀏覽器

Microsoft Windows 11 Edge 瀏覽器

Microsoft Windows Server 2008 Edge 瀏覽器

Microsoft Windows Server 2012 Edge 瀏覽器

Microsoft Windows Server 2016 Edge 瀏覽器

Microsoft Windows Server 2019 Edge 瀏覽器

教學：

1. 打開 Edge 瀏覽器

2. 右上方「...」 \ 設定 \ 隱私權、搜尋與服務 \ 最下面的「服務」\ 網址列和搜尋 \ 在網址列使用的搜尋引擎

3. 下拉選擇 <Google搜尋引擎>
