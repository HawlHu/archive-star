<<PUBG 閃退(絕地求生)解決方案>>

解決方案：

1. 電腦硬體穩定性檢查 。

使用軟體：MemTest(記憶體檢查)、OCCT(顯示卡與顯示卡記憶體檢查)、Crysis(綜合穩定性測試)

2. 檢查PUBG檔案是否損毀 。

使用 STEAM 內建驗證檔案功能。

3. 清除 STEAM 快取 。

4. NVIDIA/ AMD顯卡驅動更新版本 。

5. 使用 MSI Afterburner 固定顯示卡風扇轉速調高 (避免顯示卡記憶體過熱導致遊戲不穩定) 。

6. 移除所有防毒軟體 ，包含 Windows 內建防毒。

7. 關閉Windows UAC 功能。

8. 用Windows 最高權限遊玩或者使用最高權限啟動遊戲一次， (讓遊戲自動更新防外掛程式版本)。

9. 關閉 HPET，由BIOS 或者裝置管理員中關閉 (參閱：https://silicophilic.com/disabling-hpet-settings/) 。

10. 由NVIDIA/ AMD顯示卡設定介面中，將 FPS 鎖在最高不超過 60 FPS。

11. 嘗試降低 PUBG 內之視覺特效(如：光影效果關閉) 。

12. Windows 切換到純英文輸入法 。

13. 改使用中華浮動IP來進行遊戲(或換其他IP) 。

14. 作業系統使用 Windows 10 並安裝全部升級/ 修補包。

15. 停用ASLR。

16. 停用TPM。

17. 適度增加CPU電壓。

18. 使用最高權限指令：「sfc /scannow」，檢察系統是否有檔案損壞。

19.使用最高權限指令：「DISM.exe /Online /Cleanup-Image /Restorehealth」，檢察系統是否有檔案損壞。
