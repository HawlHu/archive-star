Chrome瀏覽器使用公共解析Public DNS說明：

本文指導您如何在 Chrome 瀏覽器中設定公共 DNS，以提高網路連線的效能和安全性。

操作包括獲取設定資訊和在瀏覽器中設定公共 DNS，確保更可靠的網路瀏覽體驗。這個過程簡化了 DNS 設定，讓使用者更輕鬆地使用公共 DNS 服務。。

 

Chrome瀏覽器使用公共解析Public DNS適用：

Chrome For Windows 8.1

Chrome For Windows 10

Chrome For Windows 11

Chrome For Windows Server 2012

Chrome For Windows Server 2016

Chrome For Windows Server 2019

Chrome For Windows Server 2021

 

Chrome瀏覽器使用公共解析Public DNS步驟：

    1. 在 Chrome 瀏覽器的網址列，點選 ... 圖示。
    2. 在展開的選項中，點選【設置】​。
    3. 在 Chrome 瀏覽器設定頁面，點選【隱私設置和安全性】​。
    4. 在隱私設定和安全性選項中，點選【安全】​。
    5. 在安全設定頁面的​【進階】，啟用【使用安全DNS】​並輸入在 DNSPod 管理控制台獲得的【DNS Over HTTPS】。

      說明：如果您使用公共解析 Public DNS 基礎服務，請輸入 https://doh.pub/dns-query。
    6. 完成設定後，即可在 Chrome 瀏覽器中成功接入 Public DNS。
