WINDOWS內建防毒之軟體排除清單設置說明：

使用 PowerShell，您可以識別對 Windows Defender 配置設置所做的修改。這些修改可以是在文件夾目錄或進程級別上添加的排除項。這些排除項用於告訴 Windows Defender 在掃描期間忽略特定的文件夾或進程，以減少對系統性能的影響。

為了執行這個任務，您可以使用 PowerShell 的相關命令和函數。這些命令和函數可讓您查詢和修改 Windows Defender 的配置設置。

舉個例子，您可以使用 Get-MpPreference 命令來查詢 Windows Defender 的配置設置。這將返回一個對象，其中包含了許多配置選項，包括排除項。您可以查看這些排除項，以確定是否有任何已設置的排除項。

如果您想要添加一個排除項，您可以使用 Add-MpPreference 命令。這個命令允許您指定要添加的排除項的路徑或進程。例如，如果您想要將一個文件夾添加到排除項中，您可以執行以下命令：

Add-MpPreference -ExclusionPath "C:\Path\To\Folder"

這將將指定的文件夾添加到 Windows Defender 的排除項列表中，使其在掃描期間被忽略。

同樣地，如果您想要添加一個進程到排除項中，您可以使用 Add-MpPreference 命令的-ExclusionProcess參數。例如：

Add-MpPreference -ExclusionProcess "ProcessName.exe"

這將將指定的進程添加到 Windows Defender 的排除項列表中。

通過使用這些 PowerShell 命令和函數，您可以輕鬆識別和修改 Windows Defender 的配置設置，以添加排除項並根據需要保護您的系統。

WINDOWS內建防毒之軟體排除清單設置 - 解決Windows 11 無法運行PS1檔案：

1. 開啟 PowerShell 並以系統管理員身份執行：

  • 在開始菜單或工作列的搜尋欄中，輸入「PowerShell」。
  • 在搜尋結果中，找到 PowerShell 應用程式。
  • 按住 Ctrl 鍵並右鍵點擊 PowerShell 應用程式的圖示。
  • 在右鍵選單中，選擇「以系統管理員身份執行」。

2. 開啟 PowerShell 的管理者模式後，輸入以下指令以修改執行策略：

Set-ExecutionPolicy Bypass

3. 按下 Enter 鍵執行指令。系統會要求您確認執行策略的更改。

4. 請輸入 Y 或 A 來確認更改。按下 Enter 鍵繼續。

5. 完成以上步驟後，您的電腦將可以正常運行 PS1 檔案了。

請注意，修改執行策略可能會增加系統的安全風險。在執行這些檔案之前，請確保您信任來源並了解檔案的內容。完成後，您可以選擇將執行策略恢復為原始設定，以提高系統的安全性。
