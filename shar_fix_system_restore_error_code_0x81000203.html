<<系統還原出現錯誤0X81000203解決>>

教學適用：

Windows 8

Windows 8.1

Windows 10

Windows 11

 

教學詳細步驟[1]：

1. 使用管理員權限打開 [regedit] (登陸檔編輯器)

2. 打開路徑：

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Class\{71a27cdd-812a-11d0-bec7-08002be2092f\

3. 檢查裡面是否存在參數：

"UpperFilters"

內容值(字串)：

"Volsnap"

如不存在，請建立。

4. 重啟電腦。

 

登陸檔案範例[1]：

Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SYSTEM\ControlSet001\Control\Class\{71a27cdd-812a-11d0-bec7-08002be2092f}]
UpperFilters"=hex(7):76,00,6f,00,6c,00,73,00,6e,00,61,00,70,00,00,00,00,00
