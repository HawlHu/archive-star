<<Intel AVX模擬>>

INTEL SDE 說明：

以下教學解決舊CPU在不支持硬體SSE4/ AVX/ AVX-512指令集的情況下，能正常使用需SSE4/ AVX才能啟動的應用程式或者電腦遊戲。

 

INTEL SDE 解決方案：

使用 <Intel Software Development Emulator>。

 

INTEL SDE 使用方式 - 使用PID方式：

1. 到<Intel Software Development Emulator> 下載 「sde-external-8.69.1-2021-07-18-win.tar.bz2」並解壓。

2. 啟動「應用程式」(例如：NBA 2K22)

3. 跳出應用程式(ALT+TAB)後，打開「工作管理員」，查看該應用程式的「PID」(假設為PID：1168)

4. 使用「指令模式」下達以下指令：

"C:\Program Files (x86)\sde\sde.exe" -attach-pid 1168

(假設SDE安裝路徑為 C:\Program Files (x86)\sde\)

5. 回到「應用程式」。

 

INTEL SDE 使用方式 - 使用EXE呼叫方式：

1. 到<Intel Software Development Emulator> 下載 「sde-external-8.69.1-2021-07-18-win.tar.bz2」並解壓。

2. 使用「指令模式」下達以下指令：

"C:\Program Files (x86)\sde\sde.exe" -hsw -- "NBA2K22.exe"

(假設SDE安裝路徑為 C:\Program Files (x86)\sde\)

INTEL SDE 關鍵字：

The following tutorial solves the problem of using applications or computer games that require SSE4/AVX to start, on old CPUs that do not support the SSE4/AVX/AVX-512 instruction set.

以下のチュートリアルは、古いCPUではサポートされていないSSE4/AVX/AVX-512命令セットを必要とするアプリケーションやコンピュータゲームを正常に使用する方法を解決します。

다음 가이드는 SSE4/AVX/AVX-512 인스트럭션 세트를 지원하지 않는 구버전 CPU에서 SSE4/AVX를 요구하는 응용 프로그램이나 컴퓨터 게임을 정상적으로 사용할 수 있는 방법을 해결합니다.
