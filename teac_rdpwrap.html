<<Windows 10多人同時登入>>

說明：

  • 使家用版作業系統，支援遠端桌面伺服器功能。
  • 使專業版以上作業系統，遠端桌面功能支援2人以上連線。(原始只支援1人)

使用範圍：

  • Windows 7 (Windows Server 2008) x86/ x64
  • Windows 8 (Windows Server 2012) x86/ x64
  • Windows 8.1 (Windows Server 2012r2) x86/ x64
  • Windows 10 (Windows Server 2016/ 2019) x86/ x64

 

教學：

  1. 到網址 https://github.com/stascorp/rdpwrap下載最新版本
  2. 下載檔案解開後, 執行 install.bat (使用管理者權限)
  3. 依Windows版本號，去Google搜尋、下載與替換 C:\Program Files\RDP Wrapper\rdpwrap.ini 檔案、內容。
    [範例: Windows 10 19042.572]
  4. 安裝 windows update blocker 程式, 暫時不要讓windows自動更新版本，避免Windows更新版本後，又需破解一次。

 

針對Windows XP：

本教學不支援 Windows XP ，有關 XP 的 RDP 多人連線，可以改使用 <universal-termsrvdll-patch> 。
