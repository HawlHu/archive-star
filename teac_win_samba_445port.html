<<TCP 445 Port問題解決>>

說明：

當發生Windows的Samba服務(網路芳齡)的 139 或者 445 Port 無法正常出現 TCP Listen 或者異常時，可依據下方教學進行排除問題。

適用：

Windows 7/ 8/ 8.1/ 10/ 11

Server 2008/ Server 2012/ Server 2016/ Server 2019

教學：

1. 檢查服務(services.msc)是否有「啟動」。

TCP/IP NetBIOS Helper(lmhosts)

Server(LanmanServer)

2. 檢查登陸(Regedit)。

A. HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\NetBT\Parameters\TransportBindName 內容需為「\Device\」

B. HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\NetBT\Parameters\SMBDeviceEnabled 移除該參數

3. 網路卡之「分享服務」重新安裝。

A. 網路卡中的「file and printer sharing for microsoft networks」移除並重新安裝。

B. 網路卡 \TCPv4 中 「進階 \WINS \NetBIOS」 設定為「開啟」或者「預設值」。

C. 移除網路卡驅動並重新安裝驅動，或者更換驅動程式版本。

4. 重啟電腦。
