<<Windows Home User Access>>

Windows Home User Access說明：

一個「應用程式」(Windows Home User Acces)，提供解決 Windows 家用版之權限設定功能，無法設定為複數權限(同一個帳號同時有兩個權限)，或者Windows 家用版作業系統權限設定，沒有 Remote Desktop User 群組可以提供運用等問題解決。

 

Windows Home User Access支援：

Windows Vista 家用版 32/ 64位元。

Windows 7 家用版 32/ 64位元。

Windows 8 家用版 32/ 64位元。

Windows 8.1 家用版 32/ 64位元。

Windows 10 家用版 32/ 64位元。

Windows 11 家用版 32/ 64位元。

 

Windows Home User Access使用教學：

第一次使用：

1. 使用「最高權限」啟動 Regedit 。

2. 將 「 HKEY_LOCAL_MACHINE\SAM\SAM 」 使用權限中的 「Administrators 群組」改為「完全控制」。

3. 註冊 「 Windows Home add RDU group.reg 」 檔案。

後續使用：

1. 使用「最高權限」啟動 「 Windows Home User Access.exe 」 。

2. 點選左邊的「欲設定的帳號」。

3. 點選右邊功能(權限更改、帳號停用啟用)。
