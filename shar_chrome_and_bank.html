<<解決CHROME無法正常使用銀行服務>>

說明：

大部分的銀行網站要登入、交易時，需安裝專用電腦軟體元件，並搭配<晶片讀卡機>來登入銀行、使用各項線上金融服務。

但使用 CHROME 有時會無法正常登入、與晶片讀卡機連線。其中一項原因就是 <HSTS> 在作怪。

<HSTS>會將網站強制導向使用 https 。而通常 Chrome 就是使用 「http://localhost:xxxxx/」 方式與銀行提供的工具進行連線，

但 <HSTS> 又將網址強制導向「https://localhost:xxxxx/」，導致無法與銀行提供的工具進行連線。

 

適用：

Google Chrome 瀏覽器

Microsoft Edge 瀏覽器

 

解決方案：

1. 啟動 Chrome 瀏覽器

2. 在網址列輸入網址 「chrome://net-internals/#hsts」，按下 Enter

3. Delete domain security policies \ Domain 欄位輸入 「localhost」

4. 按下右邊 Delete 按鈕。
