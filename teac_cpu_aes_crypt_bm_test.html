<<CPU AES 加解密效能測試>>

 

CPU AES 加解密效能測試說明：

以下為 CPU 抽樣之 「AES 加解密」效能測試，使用 VeraCrypt (硬碟加密軟體)，提供之「性能測試工具」當測試基準。

部分 CPU支援硬體 AES-NI指令 ，將以 AES-NI 打開狀態下進行性能跑分測試。

與目前主流CPU天梯測試方法之差異在於，本測試不考慮CPU功耗、售價等相關參數，只針對單一性能指標進行測試。

 

CPU AES 加解密效能測試環境：

測試軟體：VeraCrypt 1.24 ~ 1.25.9

測試方法：VeraCrypt benchmark: Encryption Algorithm Performance

採樣參數：AES 讀寫效能平均

測試資料量：200MB ~ 1GB

1. 作業系統環境：Microsoft Windows 7 ~ 11 統一使用 x64

2. 作業系統環境：Microsoft Windows XP x32
