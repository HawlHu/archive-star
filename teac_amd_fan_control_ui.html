<<AMD顯示卡風扇轉速調整>>

 

AMD顯示卡風扇轉速調整教學 - 說明[4][5]：

無論是 AMD/ NVIDIA顯示卡，有時候風扇為了「安靜」，轉數控制太「激進」，甚至有「 0 轉速」的狀況，導致部分顯示卡上之零件，在顯示卡工作模式進入「安靜模式」時，零件長期維持高溫下工作，最後導致「遊戲黑頻、遊戲當機甚至顯示卡壽命簡短、顯示卡燒毀」。

所以建議玩家將顯示卡風扇在 「GPU低溫狀態」時，也能「定轉」一定轉數進行顯示卡散熱， 延長顯示卡壽命、提升遊戲穩定性。

AMD顯示卡風扇轉速調整 - 教學[1][2]：

1. 安裝 AMD 顯示卡驅動 (使用官方的，不能使用Windows內建的顯示卡驅動)。

2. Windows 桌面按下滑鼠右鍵 \ AMD Catalyst Control Center。

3. 最上面一排「效能」 \ 第二排「微調」 \ 內頁右邊的「自訂」 \ 風扇微調區塊 \ 勾選「已啟動」\ 勾選「進階控制」。

4. 調整風扇轉速規則：

39度 以下 70% 轉速。

40度 以上 100% 轉速。
