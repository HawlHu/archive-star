<<Windows 10上使用FAT32>>

Windows 10上使用FAT32說明：

在現今儲存空間需求越來越大的情況下，TB等級的硬碟容量已經變得普遍且價格也越來越便宜。許多檔案的大小也常常超過數GB，甚至超過一張DVD的容量，例如某些影像備份檔案。

然而，傳統的FAT格式在早期有著磁區大小的限制，直到FAT32格式出現後，最大限制也僅為32GB（參見微軟技術支援服務的「FAT32檔案系統的限制」）。這意味著，除非使用者選擇使用NTFS格式進行磁區分配，否則1TB的硬碟只能被分割成32GB一個個的磁區（這樣的分割過程不僅冗長，還會導致大量磁碟代號的生成，帶來不便）。

為什麼現在的Windows系統還在堅持使用FAT32格式，而不是全部採用NTFS格式呢？原因很簡單：目前NTFS格式主要在Windows環境下才能正常讀寫。雖然Mac OS X也能讀取NTFS格式的檔案，但無法進行正常的寫入操作，這就造成了一個問題：雖然對方能夠讀取硬碟內容，但無法分享好的檔案。

因此，有沒有辦法讓大家都能接受的FAT32格式突破單一磁區的32GB限制呢？答案就是「FAT32format」。

「FAT32format」是一個精巧的DOS指令小程式，雖然只能在「命令提示字元」下執行，但它可以讓FAT32格式切割出單一磁區超過32GB的容量。

 

Windows 10上使用FAT32軟體支援：

Windows XP /Server 2003

Windows 7 /Server 2008

Windows 8 /8.1 /Server 2012

Windows 10 /11 /Server 2016 / Server 2019

 

Windows 10上使用FAT32教學：

    1. 下載並解壓縮「FAT32format」工具，將執行檔移到「C︰」磁區根目錄。
    2. 確認隨身硬碟的磁區代號（例如「F︰」）。
    3. 點選Windows開始鈕，進入「所有程式」→「附屬應用程式」→「命令提示字元」。
    4. 在命令提示字元中，輸入「cd\」回到「C︰」根目錄。
    5. 輸入「fat32format f:」（f:代表隨身硬碟的磁區代號）並按下Enter鍵。
    6. 確認格式化此磁區的提示，輸入「y」並按下Enter鍵確認。
    7. 格式化完成後，顯示相關資訊。
    8. 在Windows底下檢查磁碟內容，確認檔案系統為FAT32，並可看到磁碟單槽容量達到55.8GB。

Windows 10上使用FAT32注意事項：

雖然「FAT32format」工具可以將FAT32格式化成超過32GB的單一磁區，但單一檔案大小仍然受限於4GB的限制。

通常除了影片備份檔案外，很少會出現單一檔案超過4GB的情況。 以上是使用專業步驟進行FAT32格式化的指引。

請注意在執行此工具時，需自行確認磁區代號以及注意單一檔案大小的限制。

Windows 10上使用FAT32關於檔案系統：

檔案系統是一種用於向使用者提供底層資料存取的機制。它將裝置中的空間劃分為特定大小的塊（或者稱為簇），一般每塊512位元組。資料儲存在這些塊中，大小被修正為占用整數個塊。由檔案系統軟體來負責將這些塊組織為檔案和目錄，並記錄哪些塊被分配給了哪個檔案，以及哪些塊沒有被使用。

不過，檔案系統並不一定只在特定儲存裝置上出現。它是資料的組織者和提供者，至於它的底層，可以是磁碟，也可以是其它動態生成資料的裝置（比如網路裝置）。

檔名： 在檔案系統中，檔名是用於定位儲存位置。大多數的檔案系統對檔名的長度有限制。在一些檔案系統中，檔名是大小寫不敏感（如「AAA」和「aaa」指的是同一個檔案）；在另一些檔案系統中則大小寫敏感。大多現今的檔案系統允許檔名包含非常多的Unicode字元集的字元。然而在大多數檔案系統的介面中，會限制某些特殊字元出現在檔名中。（檔案系統可能會用這些特殊字元來表示一個裝置、裝置類型、目錄字首、或檔案類型）然而，這些特殊的字元會允許存在於用雙引號內的檔名。方便起見，一般不建議在檔名中包含特殊字元。

檔案相關資料（Metadata）： 其它檔案儲存資訊常常伴隨著檔案自身儲存在檔案系統中。檔案長度可能是分配給這個檔案的區塊數，也可能是這個檔案實際的位元組數。檔案最後修改時間也許記錄在檔案的時間戳中。有的檔案系統還儲存檔案的建立時間，最後存取時間及屬性修改時間。（不過大多數早期的檔案系統不記錄檔案的時間資訊）其它資訊還包括檔案裝置類型（如：區塊數，字元集，套介面，子目錄等等），檔案所有者的ID，組ID，還有存取權限（如：唯讀，可執行等等）。

安全存取： 針對基本檔案系統操作的安全存取可以通過存取控制列表或capabilities實現。研究表明存取控制列表難以保證安全，這也就是研發中的檔案系統傾向於使用capabilities的原因。然而目前多數商業性的檔案系統仍然使用存取控制列表。

 

Windows 10上使用FAT32關於FAT32檔案系統：

FAT12： 為了解決FAT16對於卷大小的限制同時讓DOS的真實模式在非必要情況下不減少可用常規記憶體狀況下處理這種格式，微軟公司決定實施新一代的FAT，它被稱為FAT32，帶有32位元的叢集數，目前用了其中的28位元。

理論上，這將支援總數達268,435,438（<228）的叢集，允許磁碟容量達到8TB。

FAT32隨著Windows 95 OSR2發布，儘管需要重新格式化才能使用這種格式並且DriveSpace 3（Windows 95 OSR2和Windows 98所帶版本）從來都不支援這種格式。Windows 98提供了一個工具用來在不遺失資料的情況下將現有的硬碟從FAT16轉到FAT32格式。在NT產品線上對於它的支援從Windows 2000開始。

Windows 2000和Windows XP能夠讀寫任何大小的FAT32檔案系統，但是這些平台上的格式化程式只能建立最大32GB的FAT32檔案系統。Thompson and Thompson（2003）寫道「奇怪的是微軟公司說這種現象是故意設計的」[4] 微軟公司知識庫文章184006[5]的確是這麼說的，但是沒有提出任何關於這個限制的合理解釋。Peter Norton的觀點是「微軟公司在有意地削弱FAT32檔案系統」[6]
