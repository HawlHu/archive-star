<<Smart Port Forwarding>>

說明：

Smart Port Forwarding (SPF)，此小巧工具允許在Windows作業系統中 Listen 一個 TCP Port，然後將發到此Port的任何網路封包，轉向另一個IP(Host)的TCP Port中。

可以結合 <VPN> 軟體，達到防火牆穿透功能。並可以搭配 <RunAsService> 註冊到服務中。

軟體支援：

Windows XP /Server 2003

Windows 7 /Server 2008

Windows 8 /8.1 /Server 2012

Windows 10 /11 /Server 2016 / Server 2019

 

適用穿透TCP協議(Port)：

HTTP(80)/ RDP(3389) / SSH(22) / HTTPS(443)/ Teamviewer(5938)/ Samba(445)/ MySQL(3306)

SMTP(25)/ POP3(110)/ HTTP Proxy(8080)/ SockProxy(1080)/ MSSQL(1433) ... 等

 

不建議使用之協議：

FTP(21)/ Print Server(515, 9100)

 

範例：

透過電腦1穿透80Port 到電腦2上的Web Server：

網際網路 <-PPPOE-> 數據機 <-NAT 80 Port->電腦1(80 PORT) <-> SPF <-區域網路-> 電腦2 (80 PORT)

透過電腦1穿透80Port 到VPN網路中的電腦2上的Web Server：

網際網路<-PPPOE-> 數據機<-NAT 80 Port-> 電腦1(80 PORT) <-> SPF <-VPN網路-> 電腦2 (80 PORT)

透過電腦1穿透3390 Port 到VPN網路中的電腦2上的遠端桌面(3389)：

網際網路<-PPPOE-> 數據機<-NAT 3390 Port-> 電腦1(3390 PORT) <-> SPF <-VPN網路-> 電腦2 (3389 PORT)
