<<關閉打開IE瀏覽器強制跳轉EDGE瀏覽器>>

關閉打開IE瀏覽器強制跳轉EDGE瀏覽器說明：

微軟自從推出Windows 11後，便把IE瀏覽器排除在外，並且在2022年6月15日全面終止對IE瀏覽器的支援，

但如果有的政府機關或銀行的網站上沒有支援Chrome、Edge，仍然需要用IE去開啟才能正常顯示網頁的時候，該怎麼辦呢？

如果還是想要用IE來瀏覽特定網頁的用戶不用擔心，可以利用Edge所提供的「IE相容模式」來瀏覽，不怕開啟IE瀏覽器後卻自動被改成開啟Edge！

 

關閉打開IE瀏覽器強制跳轉EDGE瀏覽器適用：

Microsoft Windows 10

Microsoft Windows 11

 

關閉打開IE瀏覽器強制跳轉EDGE瀏覽器教學：

方法1 (此方法已失效)

1. 開啟 Edge瀏覽器

2. 點選右上角的「…」圖示後，選擇「設定」。

3. Internet Explorer 相容性 \ 在 Microsoft Edge 中以 Internet Explorer 開啟網站 \ 永不。

4. 重新啟動 Edge瀏覽器。

方法2

1. 使用登陸檔(REGEDIT)：

下載：

2. 在IE路徑後面加入參數：anything -Embedding

範例： "C:\Program Files\Internet Explorer\iexplore.exe" 歸檔星球 -Embedding

方法3

1. 使用批次檔案方式：

2. 批次檔案內容如下，請將紅字部分網址改為要使用IE瀏覽器上的網站網址：
