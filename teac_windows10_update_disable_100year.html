<<停用Windows10更新100年的方法>>

說明：

Windows 10/ Windows 11的「強制更新」機制，有時會造成電腦使用上的困擾，而新版本 Windows 10 雖然有提供「暫停更新」功能，但只允許最多<<暫停更新 35 天>>，但其實只要使用 RegEdit(登陸檔編輯器) 可以突破此限制，<<教學>>如下。

 

適用：

Windows 10

Windows 11

Windows Server 2016

Windows Server 2019

步驟：

1. 修改登陸檔案：

登陸檔位置：HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings

新增參數名稱：FlightSettingsMaxPauseDays

參數類型：dword

值(16進位)：8e94 (100年)

2. 修改後，「暫停更新功能」即可突破 <<35天>> 限制。
