<<Chrome HTTP 已封鎖不安全的下載內容>>

 

教學說明：

Chrome 版本 v120 當瀏覽網站是 HTTP://xxxx， 會被顯示為 不安全 且 預設封鎖下載檔案

Chrome提示訊息：

這部裝置的任何使用者都可以看到已下載的檔案已封鎖不安全的下載內容

如果仍要下載可按【保留】

若不想要每次都按【保留】才能下載，該如何做？

 

教學適用：

Google Chrome v120以後版本

 

設定方式：

1.在 Chrome 網址列輸入 chrome://flags

2.搜尋 "download"

3.找到 Warn on insecure downloads

將 Default 改成 Disabled

4.關閉所有 Chrome 頁面重新開啟chrome
