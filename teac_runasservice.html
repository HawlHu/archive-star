<<應用程式變服務(Pirmasoft RunAsSvc)>>

應用程式變服務(RunAsSvc)說明：

Pirmasoft RunAsSvc 是一個小工具，允許您將一個「應用程式」轉成「服務」。

使用此工具安裝的「任何服務」，需將此工具保留在安裝服務時，當時的路徑(資料夾)，以便這些安裝的服務可以正常運作。

 

應用程式變服務(RunAsSvc)適用：

Windows XP

Windows 7

Windows 8

Windows 8.1

Windows 10

Windows 11

Windows Server 2003

Windows Server 2008

Windows Server 2012

Windows Server 2016

Windows Server 2019

Windows Server 2021

 

應用程式變服務(RunAsSvc)教學：

 

建立服務：

1. 先將 runassvc.exe 複製到 c:\windows\system32\ 資料夾中

2. 啟動 runassvc.exe

3. 設定「服務執行檔路徑」、「服務名稱」、「執行階段資料夾」等資訊

4. 按下確定紐

 

移除服務：

至「新增移除程式」找 Pirmasoft RunAsSvc + 服務名稱項目，按下移除。

 

使用指令來新增服務範例：

"c:\windows\system32\RunAsSvc.exe" -i --displayname "Parking Task Service" --exe "C:\Program Files\web\php_artisan_schedule.bat" --description "網站排程功能，請勿停用。" --params "-m" --workingdir "C:\Program Files\web\docs_parking" --quiet
