<<Sambar綜合伺服器介紹>>

Sambar綜合伺服器說明[1]：

<<軟體簡介>>

每次總是輸入網址 http://xxx.xxx.xxx.xx/ 連線到別人的網頁上去，想不想自己也架設一個網站？提供你一個簡單好用、具有內建網頁搜尋器、FTP 伺服器、Perl 5、HTML方式操作的管理及設定環境，最重要的是完全免費的。 由於此套軟體強大的功能實在無法一一介紹，因此只挑其中要將「個人電腦」變成伺服器的方法講解。

1. 假設你的電腦IP是：192.168.2.12

2. 下載 Sambar Server 後，它是一個壓縮檔，所以必須先用解壓縮程式，先將他解到暫存的目錄下，然後執行 setup.exe 即可開始安裝。

3. 安裝完後，只要執行【程式集】中的【 Sambar Server】，就可以將你的個人電腦變成一台伺服器，此時按下〔Hide〕將 Sambar Server 最小化，打開瀏覽器鍵入「 http://192.168.2.12 」就可以看到自己電腦中 Sambar 的預設網頁，只要將你自己的網頁放到「Sambar」下面的「 docs 」目錄裡，那進入剛剛那個網址就可以看到自己的網頁了。

現在大部份的網路主機還是以 unix 為主，因此 cgi 的程式 也是以 perl 語言為大宗，利用 Sambar Server 就可以執行你的 cgi 程式，然後再放到正式網路主機上，可以節省上載測試的時間。

Sambar Server 擁有的功能：

支援 HTTP、SMTP、POP3、IMAP4、NNTP、Bridge 的 Proxy 設定。

內建系統報告及 LOG 分析功能。

支援 CGI/1.1 、WINCGI 、ISAPI Mappings

前面所敘述的都是個人電腦的應用，本套軟體也適合架設在伺服器上。
